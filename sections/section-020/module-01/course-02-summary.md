# Summary

Cilium installation requires a compatible host, runtime and network design as well as Kubernetes resources. Component readiness and endpoint preparation are separate from the fact that installation objects were created.

Connectivity tests provide evidence for their selected scenarios, with permissions and temporary workloads as dependencies. They do not prove every production path or policy, and this reading course explains their meaning without creating or executing a test environment.
