# Summary

The remote Cilium CLI manages or inspects a cluster through Kubernetes access, while local debugging addresses an individual agent. Correct context and permissions are prerequisites for meaningful results.

A configuration change is desired state until the relevant components load and realize it. Supported versions, rollout behavior and durable ownership must agree; one successful management response does not establish universal endpoint or feature readiness.
